> 本仓库验证成果：用 **2023 高教社杯 C 题《蔬菜类商品的自动定价与补货决策》** 真实题目，完整跑通了「建模+编程岗 → 论文岗 → Gitee 协同交接 → 独立评审」全流程。
>
> - 协作仓库：`math-team/`（Gitee）
> - 分工：member-a（建模+编程）→ 交付 Q1–Q4；member-c（论文）→ 成稿/评审/识图质检
> - 全部数据真实来自题目附件，全文数字可溯源到 `results/` 与图表

## 一、题目与数据

- **题目**：2023 高教社杯 C 题（蔬菜类商品的自动定价与补货决策），4 个子问题
- **数据规模**：
  - 附件1：251 单品 / 6 品类
  - 附件2：销售流水 **878,503 行**（2020-07-01 ~ 2023-06-30，含退货，打折标记）
  - 附件3：批发价格 55,982 行
  - 附件4：损耗率（6 小分类 + 251 单品）

## 二、协作链路（A → C）

```
member-a（建模+编程岗）
  ├─ 题目分析报告.md      ← 读题、拆子问题、建模约束
  ├─ 术语表格.md
  ├─ 问题1~4 求解脚本      ← 真实运行
  ├─ results/             ← 分布/关系/量价/补货方案/灵敏度 CSV + 复现清单.json
  └─ figures/             ← raw/process/result 三类，覆盖 Q1–Q4
        │  git add member-a && push
        ▼
member-c（论文岗） git pull
  ├─ W1 证据大纲.md
  ├─ 论文.tex + 论文.pdf   ← XeLaTeX 编译（TinyTeX）
  ├─ 代码/                ← 附录 B 核心代码（只读 member-a 复制，未改动）
  ├─ 评审记录.md           ← W1/W2/独立评审/多轮修复迭代
  └─ ai使用声明.md
```

全程**只提交各自 `member-*` 文件夹**，互不干扰；论文证据全部来自 member-a 真实交付物。

## 三、成员 A（建模+编程岗）成果

### 问题 1 — 分布规律与相互关系
- 单品销量**长尾集中**：Top5 占 25%、Top25 占 64%、Top50 占 84%
- 单日-单品销量右偏（均值 ≈10.1 kg / 中位 5.2 kg），对数正态拟合 AIC 优于伽马（304,372.5 < 660,894.3）
- **周内季节因子**：周五 18.2%、周六 17.6% ≫ 工作日 12.4%~12.8%
- 季节波动：7–9 月（夏）与 1 月（春节）双高
- 品类相关：多为弱-中度正相关，**茄类相对独立**（Pearson 0.07~0.31）
- 打折识别价格敏感样本（5.4% 打折，约 7~8 折）

### 问题 2 — 品类量价关系 + 未来一周补货定价
- 常弹性需求函数（含价格弹性 + 周内/季节/节假日因子），2SLS 校正
- 弹性估计：花叶 -0.364、辣椒 -0.647（价升量降）
- 未来一周（7-1~7-7）各品类日补货量 + 加成率定价策略
- **滚动回测收益改进 +56.2%**（8289.98 vs 5589.42）

### 问题 3 — 单品补货（27–33 个）
- 可售 49 单品中选入 **33 个**，每单品补货 ≥2.5kg
- 入选依据 = **单位陈列量利润潜力**（空间约束导向）
- 需求满足率下界灵敏度扫描 + 满意度-收益权衡
- 7月1日单日收益优化

### 问题 4 — 数据采集建议
基于建模实际缺口提出 7 类待采数据（当日实际进价、真实需求量、促销/陈列、动态损耗、天气客流、退货原因、客户画像），逐项说明受益问题与理由。
