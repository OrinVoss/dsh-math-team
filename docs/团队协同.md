# 团队协同说明

3 人团队协作模型：**3 个独立工作区 + 3 个独立文件夹 + 通过一个 Git 仓库协同，互不干扰。**

## 核心规则（每个人都遵守）

1. **只提交自己那个 `member-*` 文件夹** —— 用 `git add member-a`（或 member-b / member-c），**绝不 `git add .`**
2. 每次开工先 `git pull`，避免基准过期
3. 若报 `schannel ... SEC_E_NO_CREDENTIALS (0x8009030e)`，先执行：
   ```bash
   git config http.sslBackend openssl
   ```
   需要代理时再加：`git config http.proxy http://127.0.0.1:10808`
4. `git pull` 只读别人文件夹，绝不覆盖改写

## 仓库结构

```
<repo>/
├── member-a/    # 建模+编程成员 A
├── member-b/    # 建模+编程成员 B
└── member-c/    # 论文岗成员 C
```

## 初始化（仓库为空时，首个成员执行一次）

```bash
git clone <git-repo-url>
cd <repo>
mkdir -p member-a member-b member-c
printf '建模编程成员 A\n' > member-a/README.md
printf '建模编程成员 B\n' > member-b/README.md
printf '论文岗成员 C\n'   > member-c/README.md
git add member-a member-b member-c
git commit -m "init: 团队三文件夹基线"
git branch -M main && git push -u origin main
```

## 交付物契约

- **建模+编程岗**：`题目分析报告.md`、`术语表格.md`、求解脚本（.py/.m）、`results/`（结果表+复现清单.json）、`figures/`（原始/过程/结果三类图，覆盖全部子问题）
- **论文岗**：`W1_证据大纲.md`、`完整论文.docx|.md|.pdf`、`评审记录.md`、必要时 `ai使用声明.md`

## 质量门禁

- 建模+编程岗：`M1 建模终检 → P1 最小可运行 → P2 编程终检 → 复现验证`
- 论文岗：`W1 证据大纲 → 证据检索核验 → W2 论文终检`
- 保留独立评审门禁（严重度 blocker/high/medium/low + 有界迭代预算）

### 独立模型审查（对抗式评审）

为了跳出主模型盲区，**独立评审/质检子代理应指定与产出方不同的模型**（不同厂商效果更佳），做对抗式挑错与独立判断。这能拦截主模型自审时忽略的缺陷（编造数值、口径不自洽、推荐矛盾、编造引用等）。

- **推荐审查模型**：`kimi-coding / k3-256k`（本环境已验证，26 万上下文，支持 text+image）。换部署后先用 `llm` 服务探测一个 `provider` 与主模型不同的模型，**不硬编码**。
- 用 `workflow` 的 `agent(prompt, { provider: <审查provider>, model: <审查model> })` 派发审查子代理。
- 审查要求：事实性（数值可溯源、无编造）、一致性（口径/符号/结论自洽）、完备性（覆盖全部子问题）、独立判断（给 `通过/不通过` + 必须修复的证据项，按严重度）。
- `不通过` 按证据回退修正后复验；主模型不得口头覆盖审查 FAIL。
- 若环境无 `provider` 与主模型不同的审查模型，如实标记"独立评审受限"。

## 各岗位开工口令

### 成员 A / B —— 建模+编程岗（会话选 `model-code` 预设）
```
使用 math-model-code skill，执行团队 Git 协同初始化：
1. 仓库 URL = <git-repo-url>（报 schannel 错就先 git config http.sslBackend openssl）
2. git clone 到我的独立工作区
3. 在 member-a/（或 member-b/）内完成题目：【粘贴题目】
4. 产出 题目分析报告.md、术语表格.md、求解脚本、results/、figures/，只 git add 我的 member 文件夹
5. 达标 M1→P1→P2 门禁后 push 到 main
```

### 成员 C —— 论文岗（会话选 `paper` 预设）
```
使用 math-paper skill，执行团队 Git 协同：
1. 仓库 URL = <git-repo-url>（报 schannel 错就先 git config http.sslBackend openssl）
2. git clone 到我的独立工作区，git pull
3. 读取 member-a/、member-b/ 的交付物
4. 写 W1 证据大纲 → 完整论文 → 评审记录，只 git add 我的 member-c 文件夹
5. 达标 W1→W2 门禁后 push 到 main
```

## 任务分工示例（以某 4 子问题竞赛题为例）

- **成员 A**：问题 1 + 问题 2（数据分布与关联分析、品类定价-销量建模与周补货优化）
- **成员 B**：问题 3 + 问题 4（单品补货组合优化、数据采集建议）
- **成员 C**：整合 A、B 结论撰写完整论文

数据可放共享路径（各会话同机可访问）或仓库 `data/`（自备，避免大体积二进制约束）。
